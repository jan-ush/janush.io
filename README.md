# Portfolio Template

A minimal Next.js portfolio site you can deploy immediately, then customize over time.

## Getting Started

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Customize

- Edit the page content in `app/page.tsx`.
- Update the site title and description in `app/layout.tsx`.
- Adjust colors and spacing in `app/globals.css`.
- Add future pages under `app/`, for example `app/projects/page.tsx`.

## Deploy

This project is ready for common Next.js hosts such as Vercel, Netlify, or any platform that supports `npm run build` and `npm start`.
